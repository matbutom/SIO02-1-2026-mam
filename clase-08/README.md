## ideas para desarrollar el ensayo

estudiar 2 o 3 textos bien para poder ponerlos en diálogo con nuestras ideas para desarrollar el ensayo

conocer las referencias más canónicas de las bases del arte medial (benjamin, manovich, etc)

definir un índice tentativo

analizar obras de forma forence y hacerle preguntas

tematizar el error en la obra

dadaísmo - objetos dadaistas

concepto del error

definir pregunta específica para agrupar obras desde el diseño a la experiencia artística

derrotero - proceso derrotero - camino para llegar a un sitio

mostrar el ser de la máquina, su performalidad material

colapso de la máquina

forzar/saturar/desgastar las posibilidades performativas del material
